Платформа «Invex»

Инвестиционный дашборд для частных инвесторов с AI-аналитикой

👉 Смотреть демо

📌 Задача

Клиент — финансовый стартап из Лондона. Нужно было создать единую платформу, где инвесторы могут:

  • Отслеживать портфель в реальном времени
  • Получать AI-прогнозы по акциям и криптовалютам
  • Строить кастомные дашборды без кода

Главные требования: высокая производительность при загрузке больших объёмов данных и мобильная адаптивность.

⚙️ Решение

Мы разработали SPA на React + Node.js с использованием WebSocket для стриминга данных. Ключевые фичи:

  • Адаптивный дашборд с виджетами, перетаскиваемыми в реальном времени
  • AI-модуль на Python (FastAPI) для прогнозирования
  • Кэширование через Redis для мгновенной загрузки истории

Интерфейс построен на компонентной архитектуре, что позволило легко масштабировать проект и добавлять новые виджеты.
